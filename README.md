# Customer Churn Analytics

## Overview
Customer Churn Analytics is a machine learning web application designed to predict customer churn and present the results through interactive visualizations.

## Features
- Customer churn prediction based on customer information.
- Interactive dashboard for exploring churn-related insights.
- Visual representation of churn probability.
- Data visualizations and prediction results.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly

## How to Run Locally

1. Clone this repository.
2. Install the required dependencies.
3. Run the Streamlit application.

```bash
pip install -r requirements.txt
streamlit run app.py
```
